Libraries und Suchpfade

Mit IMPORT können externe YAB-Dateien als Libraries in ein Programm eingebunden werden.

Suche nach Libraries

Wird eine Library mit IMPORT eingebunden, sucht YAB die entsprechende Datei in einer festgelegten Reihenfolge.

  1. im Verzeichnis des Hauptprogramms
  2. im Unterverzeichnis subs des Hauptprogramms
  3. im mit -librarypath angegebenen Library-Verzeichnis

Die Library wird verwendet, sobald sie an einer dieser Stellen gefunden wurde. Weitere Verzeichnisse werden danach nicht mehr durchsucht.

Beispiel

Ein Programm kann beispielsweise folgende Struktur haben:

meinprogramm.yab
meine_lib.yab
subs/
    funktionen.yab
    grafik.yab

Die Libraries können dann direkt eingebunden werden: 

import meine_lib
import funktionen
import grafik

Bei import funktionen sucht YAB zunächst im Verzeichnis des Hauptprogramms und anschließend im Unterverzeichnis subs.

Libraries über -librarypath

Mit der Option -librarypath kann ein zusätzliches Verzeichnis angegeben werden, in dem YAB nach Libraries sucht, die an den beiden lokalen Stellen nicht gefunden wurden. 

yab -librarypath /boot/home/libs meinprogramm.yab

Befindet sich beispielsweise die Library gedcom.yab in /boot/home/libs, kann sie mit IMPORT eingebunden werden: 

import gedcom

Mehrere Libraries mit gleichem Namen

Eine Library kann an mehreren Suchorten vorhanden sein. Das ist kein Fehler.

Beispielsweise:

meinprogramm.yab
test.yab
subs/
    test.yab

/boot/home/libs/
    test.yab

Bei 

import test

verwendet YAB die erste gefundene Datei. Die Suchreihenfolge ist: 

1. Verzeichnis des Hauptprogramms
2. subs/
3. -librarypath

Die Libraries an den nachfolgenden Suchorten werden nicht zusätzlich eingebunden.

Doppelte Imports

Wird dieselbe Library innerhalb eines Programms mehrfach importiert, erkennt YAB, dass die Library bereits geladen wurde. 

import test
import test

Die Library wird dadurch nicht mehrfach geladen.

BIND

Die gefundenen und eingebundenen Libraries können weiterhin mit der vorhandenen BIND-Funktion in ein gebundenes Programm übernommen werden.

Hinweis zu -librarypath

Die Option -librarypath bezeichnet weiterhin ein einzelnes zusätzliches Verzeichnis. 

-librarypath PATH

Standardmäßig wird dafür das konfigurierte YAB-Library-Verzeichnis verwendet: 

/boot/home/config/settings/yab
