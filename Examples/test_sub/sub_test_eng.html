Libraries and Search Paths

External YAB files can be included in a program as libraries using IMPORT.

Searching for Libraries

When a library is included using IMPORT, YAB searches for the corresponding file in a defined order.

  1. the directory of the main program
  2. the subs subdirectory of the main program
  3. the library directory specified with -librarypath

The library is used as soon as it is found in one of these locations. The remaining directories are not searched afterwards.

Example

A program may have the following structure: 

myprogram.yab
my_library.yab
subs/
    functions.yab
    graphics.yab

The libraries can then be included directly: 

import my_library
import functions
import graphics

When import functions is used, YAB first searches the directory of the main program and then the subs subdirectory.

Libraries Using -librarypath

The -librarypath option can be used to specify an additional directory in which YAB searches for libraries that were not found in the two local locations. 

yab -librarypath /boot/home/libs myprogram.yab

If the library gedcom.yab is located in /boot/home/libs, it can be included using IMPORT: 

import gedcom

Libraries with the Same Name

A library may exist in more than one search location. This is not an error.

For example:

myprogram.yab
test.yab
subs/
    test.yab

/boot/home/libs/
    test.yab

With 

import test

YAB uses the first file it finds. The search order is: 

1. Main program directory
2. subs/
3. -librarypath

Libraries in the remaining search locations are not included additionally.

Duplicate Imports

If the same library is imported more than once within a program, YAB recognizes that the library has already been loaded. 

import test
import test

The library is therefore not loaded more than once.

BIND

Libraries that have been found and included can still be incorporated into a bound program using the existing BIND functionality.

Note on -librarypath

The -librarypath option still specifies a single additional directory. 

-librarypath PATH

By default, the configured YAB library directory is used: 

/boot/home/config/settings/yab
